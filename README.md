### 1. Назначение программы
Программа на языке C предназначена для анализа работы облачной инфраструктуры по последовательности телеметрических измерений. Программа получает значения показателей инфраструктурных компонентов за последовательные интервалы времени, формирует временные ряды, вычисляет производные показатели динамики, выявляет инциденты по заданному правилу.

### 2. Описание индивидуального варианта
- **Вариант:** №29
- **Компоненты:** SSD, APP, LOG
- **Порядок записи:** значение — время — компонент. Разделитель: пробел.
- **Тип последовательности (6):** У одного компонента могут быть разные значения на одном отсчёте; все измерения учитываются.

**Телеметрия за пять отсчётов — одна строка:**
30.6 3 LOG 57.2 2 APP 44.7 3 SSD 33.6 2 LOG 35.2 4 LOG 31.3 2 LOG 44.2 2 SSD 55.2 3 APP 34.5 5 LOG 53.8 1 APP 50.6 4 SSD 37.5 4 LOG 51.1 5 SSD 32.0 1 LOG 53.2 4 APP 51.2 5 APP 43.7 1 SSD

**Производный показатель Q:** Квадрат относительного изменения.

**Формула:**
$$
Q[i] = \left( \frac{X[i] - X[i-k]}{X[i-k]} \right)^2; \quad k = 2; \quad L = 1.0
$$

**Правило состояния компонента (Серия отклонений):** Если \(|Q| > L\) два измерения подряд, состояние «ПРЕДУПРЕЖДЕНИЕ», иначе «НОРМА».

**Правило инцидента (Два из трёх):** Инцидент возникает, если не менее двух компонентов одновременно находятся в состоянии, отличном от «НОРМА».

**Структура Incident:**
typedef struct { int time; int type; float value; } Incident;
